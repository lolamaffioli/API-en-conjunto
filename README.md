🚀 API REST Colaborativa

📖 Descripción

Este proyecto consiste en una API REST desarrollada de forma colaborativa con el objetivo de simular un entorno de trabajo similar al de un equipo de desarrollo.

La API permite gestionar tableros, listas, tarjetas y comentarios, además de incorporar autenticación de usuarios, notificaciones e historial de cambios. Durante el desarrollo se trabajó con un repositorio remoto, utilizando ramas para implementar nuevas funcionalidades y luego integrarlas mediante Git.

✨ Funcionalidades

- Gestión de usuarios.
- Autenticación y autorización.
- Creación y administración de tableros.
- Gestión de listas.
- Creación, edición y eliminación de tarjetas.
- Sistema de comentarios.
- Notificaciones.
- Historial de cambios.

🛠️ Tecnologías utilizadas

- Node.js
- Express.js
- Base de datos (completá con la que usaron)
- Git
- GitHub

👥 Trabajo colaborativo

Este proyecto fue desarrollado por un equipo de dos personas utilizando una metodología de trabajo colaborativa.

Durante el desarrollo se implementó un flujo de trabajo basado en Git, creando ramas para cada funcionalidad, realizando integraciones al repositorio principal y resolviendo conflictos cuando fue necesario.

🎯 Objetivo

Aplicar buenas prácticas en el desarrollo de APIs REST y adquirir experiencia trabajando de manera colaborativa con herramientas de control de versiones.
